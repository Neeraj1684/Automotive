# Automotive Management System

A full-stack project for managing automotive operations using Spring Boot (Backend) and React (Frontend - upcoming).

## Tech Stack

Backend:
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL

Frontend:
- React (to be added)

Tools:
- IntelliJ IDEA
- Git & GitHub

## Project Structure

Automotive/
│
├── backend/    → Spring Boot application
├── frontend/   → React app (coming soon)
├── .gitignore
└── README.md

---

## Backend Setup

1. Go to backend folder
2. Configure database in environment variables:

DB_USERNAME=your_username  
DB_PASSWORD=your_password

3. Run the application

The server will start at:
http://localhost:8080
